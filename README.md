# PC Remote Control

브라우저만으로 다른 기기에서 이 PC의 **화면을 실시간으로 보고, 마우스·키보드를 조작**할 수 있는
가벼운 원격 데스크톱 도구입니다. 별도 클라이언트 설치가 필요 없고 Windows / macOS / Linux에서 동작합니다.

- 화면 스트리밍: MJPEG (브라우저 `<img>` 태그만으로 재생)
- 입력 제어: 마우스 이동/클릭/드래그/스크롤, 텍스트 입력, 단축키
- 접속 보호: 토큰 인증

## 동작 방식

```
[폰/노트북 브라우저]  ──HTTP──►  [server.py (이 PC)]
      화면 보기        ◄────────   mss로 화면 캡처 → JPEG 스트림
      터치/클릭         ────────►   pyautogui로 마우스·키보드 실행
```

## 설치

```bash
pip install -r requirements.txt
```

플랫폼별 사전 준비:

- **Windows**: 추가 설정 없음.
- **macOS**: `시스템 설정 → 개인정보 보호 및 보안`에서 터미널(또는 Python)에
  **화면 기록**과 **손쉬운 사용(제어 허용)** 권한을 부여해야 합니다.
- **Linux**: X11 세션에서 동작합니다. Wayland에서는 화면 캡처/입력이 제한될 수 있어
  X11 로그인 세션을 권장합니다. 헤드리스 환경에서는 실제 디스플레이가 필요합니다.

## 실행

```bash
# 토큰을 직접 지정
python server.py --host 0.0.0.0 --port 8000 --token my-secret

# 토큰 생략 시 무작위 토큰이 생성되어 콘솔에 출력됩니다
python server.py
```

실행하면 콘솔에 접속 주소와 토큰이 표시됩니다:

```
========================================================
  PC Remote Control server
  Screen      : 1920 x 1080
  Listening   : http://0.0.0.0:8000/
  Access token: h8Kd3fRt9qLm
========================================================
```

다른 기기의 브라우저에서 `http://<이-PC의-IP>:8000/` 로 접속한 뒤 토큰을 입력하면 됩니다.
(같은 네트워크에 있어야 하며, PC의 IP는 `ipconfig`(Windows) 또는 `ifconfig`/`ip addr`(macOS·Linux)로 확인)

## 옵션

| 옵션 | 기본값 | 설명 |
|------|--------|------|
| `--host` | `0.0.0.0` | 바인드할 주소 |
| `--port` | `8000` | 포트 |
| `--token` | 무작위 생성 | 접속 토큰 (환경변수 `REMOTE_TOKEN`도 사용 가능) |
| `--fps` | `15` | 화면 스트림 초당 프레임 수 |
| `--quality` | `60` | JPEG 화질 (1–95). 낮출수록 대역폭 절약 |
| `--max-width` | `1280` | 전송 화면 최대 가로 폭(px). 축소해 전송량 절감 |

## 사용법 (웹 UI)

- 화면을 **클릭/터치**하면 해당 위치를 클릭, **드래그**하면 드래그 동작.
- **우클릭: ON** 버튼을 누르면 다음 클릭이 오른쪽 버튼으로 동작합니다.
- 상단 입력창에 글자를 입력하면 PC로 전송되고, **Enter**로 엔터키를 보냅니다.
- `Ctrl+C`, `Ctrl+V`, `Esc`, `⌫` 등 자주 쓰는 키 버튼을 제공합니다.
- 마우스 휠 스크롤은 데스크톱 브라우저에서 지원됩니다.

## 보안 주의사항

- 이 도구는 **PC의 완전한 제어 권한**을 네트워크로 노출합니다. 신뢰할 수 있는 네트워크에서만,
  강력한 토큰과 함께 사용하세요.
- 트래픽은 평문 HTTP입니다. 인터넷에 직접 노출하지 말고, 필요하면
  리버스 프록시(HTTPS) 또는 VPN·SSH 터널 뒤에서 사용하세요.
- 사용하지 않을 때는 서버를 종료하세요.
